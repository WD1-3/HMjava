# 黑马点评项目总览

## 1. 这是什么项目

“黑马点评 / hm-dianping”是黑马程序员 Redis 实战课程中的项目，业务形态类似本地生活点评平台。

它真正的学习价值不在于“做一个点评网站”，而在于通过一套连续业务，把 Redis 的常见企业级使用方式串起来。

主要技术栈：

- Java
- Spring Boot
- MyBatis-Plus
- MySQL
- Redis
- Nginx

## 2. 为什么值得学

相比单独学习 Redis 命令，这个项目能看到 Redis 如何进入真实业务链路：

- 登录状态为什么可以放 Redis
- 数据库前为什么加缓存
- 缓存穿透、击穿、雪崩分别怎么产生
- 秒杀为什么会超卖
- JVM 锁为什么无法解决分布式问题
- Lua 为什么可以保证一段 Redis 操作的原子性
- 为什么秒杀下单常做异步化
- Feed、GEO、签到、UV 分别适合什么 Redis 数据结构

## 3. 本仓库的学习目标

最终不是“看完课程”，而是达到：

1. 能看懂项目结构。
2. 能顺着 Controller → Service → Mapper / Redis 阅读完整请求链路。
3. 能解释关键 Redis 设计。
4. 能在 `init` 版本自己补核心代码。
5. 能脱离课程复述关键模块的实现思路。

## 4. 推荐学习方式

以源码为中心，不脱离项目单独堆语法。

每个模块按下面顺序：

```text
业务问题
→ 找入口 Controller
→ 顺调用链读 Service
→ 找数据库 / Redis 操作
→ 标注第一次出现的重要写法
→ 自己口述数据流
→ 在 init 分支补代码
→ 卡住后再看 master
→ 总结 3~5 个真正值得记住的点
```
